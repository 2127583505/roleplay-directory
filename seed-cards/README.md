# 种子卡

这里存放 8 张**由本项目维护者创作**的示例角色卡，格式为
[Character Card V2](https://github.com/malfoyslastname/character-card-spec-v2)。

它们的用途是让目录站开箱就有内容可看，同时充当格式样例。

---

## 为什么不放在站点代码里直接读取

因为本站的架构是 **「只索引，不托管」**。

如果目录站把角色卡本体放在自己的 `src/` 或 `public/` 里直接分发，
它就变成了内容平台，要承担内容责任 —— 这正是这个项目一开始要避开的。

所以哪怕是维护者自己写的卡，也走**和所有创作者完全一样的路径**：

```
创作者自己的仓库  ──外链──▶  目录条目（只存元数据）
   seed-cards/*.json         src/content/characters/*.md
```

这也让这套种子卡成为一份**可运行的工作流示范**：
任何人照这个结构做，就能把自己的卡接进目录。

## 部署前必做

这些卡里的 `creatorUrl` 和条目里的 `source` 地址都用了
`2127583505` 占位符。跑一次：

```bash
npm run set-owner -- 你的GitHub用户名
```

所有占位符会被替换成你的用户名，同时站点地址也会一起更新。

**如果你只想删掉种子卡**，把本目录和 `src/content/characters/` 下的对应 `.md`
一起删掉即可 —— 目录站没有任何硬编码依赖。
